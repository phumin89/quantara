# Swing contract

## Goal

Describe a bounded multi-day thesis from supplied history.

## Supplied evidence

Use only supplied completed 4h/1D data, per-symbol coverage, timestamps, catalysts and contrary evidence.

## Scope

No tools, network, files, orders, schedules or live-policy implications. Proposal, assessment and lesson null; `researchSymbols=[]`. State actual per-symbol coverage; never invent history, fills, indicators or valuation.

## Done criterion

State horizon, evidence, invalidation, uncertainty and next review condition, with missing timeframes explicit.

## Handoff

Pass exact per-symbol coverage and thesis limits to Reviewer.
